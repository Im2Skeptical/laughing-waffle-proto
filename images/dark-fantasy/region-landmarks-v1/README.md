# Region landmarks and markets

Original art generated with the built-in ImageGen tool on 2026-10-08.
The existing hamlet, crisis painting, and red terrain were inspected for style.
Town, lair, and billboard masters preserve generated transparent alpha;
the repeating ground texture is opaque. Stock names and prices are drawn live.

This group packs at 40% source resolution in `region-landmarks.json`.
Map landmarks fit their complete images; the billboard uses a nine-slice frame.
Monster ground is tiled inside the authored polygon mask. No visual randomness
or simulation changes are involved.
