# Settlement illustrations

Thirty original illustrations, revised with the built-in ImageGen tool on
2026-09-12 to fill complete opaque scenes. Existing subjects, buildings, palette
and medieval painted style were preserved while extending surroundings.
`full-bleed-prompts.json` records the revision prompts and generated source names;
`prompts.json` retains the first version's provenance.

Practices render at 5:7. Structure faces render at 3:4 per horizontal cell, using
one-, two-, or three-cell footprints. Runtime artwork covers the aperture with
an aspect-preserving crop; neither art nor complete pieces are stretched.

Production paintings are WebP quality 86, bounded to 960 x 768 without distortion.
All 30 were checked opaque. The runtime atlas packs these at 80% scale into one
4096-bounded texture. Physical frames are separate in `../piece-frames-v1/`.
Quality, outputs, workers, fill, and transient placement states remain live UI.
