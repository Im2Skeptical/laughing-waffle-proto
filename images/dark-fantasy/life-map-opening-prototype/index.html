What this experiment changes

Fresh-game world, population, Stock, Retinue, action effects, mortality and elapsed time use real game rules. The authored graph, curated offers, development choices and ordinary relic Chaos penalties belong only to this workbench.

The mock screen reuses the game's Pixi Life Map, world map, settlement, HUD, node decision and inspection views. The authored graph advances through disposable encounter slots in a normal runtime graph. Stock Supply uses the current global unmet-input check.

Each ordinary node still grants the current routine Prestige and Development income. Earned ability choices remain playable. Pre-founding actions that would reach mortality age are blocked. World collapse can still end a run.

Saved experiments use separate browser storage. Nothing writes to player saves, live card reviews or the main game configuration.
