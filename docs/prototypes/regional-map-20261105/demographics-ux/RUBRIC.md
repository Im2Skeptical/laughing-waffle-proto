# Demographics UX rubric

Scores are 1-5. Anchors below are 1 / 3 / 5; 2 and 4 are intermediate.

| Dimension | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Task clarity | Purpose unclear | Purpose discoverable | Main questions answered at a glance |
| Structure/hierarchy | Flat information | Basic grouping | Primary status and secondary detail unmistakable |
| Layout efficiency | Clipping/wasted space | Usable grouping | Available space supports readable comparison |
| Signal/noise | Prose/raw dumps | Mixed summary/detail | Compact symbols/counts, detail on demand |
| Consistency | Foreign visual language | Mostly established patterns | Coherent game palette, units, icons, controls |
| Feedback/status | Ambiguous conditions | Basic status labels | Immediate, accessible normal/pressure/empty states |
| Expert efficiency | Repeated searching | Reasonable inspection | Direct comparison with one-step detail |
| Trust | Missing/ambiguous totals | Totals with partial context | Reconciled data and exact inspectable definitions |

Success: total >= best peer (34/40) and no dimension >1 below peer median.
Scoring is limited to the observed population surfaces; it is not a whole-game
usability or accessibility certification.
