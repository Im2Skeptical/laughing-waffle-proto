# Rubric

All dimensions 1–5. Same anchors for peers and prototype.

| Dimension | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Task clarity | No clear place/action | Tasks discoverable | Orientation and next action immediate |
| Structure & hierarchy | Everything competes | Primary path mostly clear | Attention follows world → place → decision |
| Layout efficiency | Chrome obscures work | Usable with crowding | Space serves the current job |
| Signal vs noise | Routine details dominate | Mixed priority | Only decision-relevant signals prominent |
| Consistency | Patterns conflict | Mostly stable | Same semantics and interaction across views |
| Feedback & status | State unclear | Selection/status readable | Immediate, distinct selection and exceptions |
| Expert efficiency | Repeated searching | Common tasks reasonable | Frequent tasks direct, context preserved |
| Trust of data | Unclear values/units | Inspectable with caveats | Units, scope and conditionality explicit |
| World readability (optional) | Map obscured | Geography visible but weak | Terrain, places and scale dominate |
| Place comparison (optional) | No useful comparison | Requires some inspection | Valuable targets and ownership easy to compare |

Success: total >= best peer total; no dimension >1 below peer median.
Do not interpret scores as empirical measurements or claim overall product parity.
